# Student Manager App

A beginner-friendly Python command-line application to manage student names and marks.

## Features

- Add students and their marks
- View all registered students
- Check student results
- Display PASS or FAIL based on marks
- Exit the application

## Technologies Used

- Python
- Dictionaries
- Loops and conditional statements
- User input and type conversion

## How to Run

1. Clone this repository.
2. Open the project folder in your terminal.
3. Run the application:

```bash
python main.py
```

## Result Criteria

- Marks greater than or equal to 40: PASS
- Marks below 40: FAIL

## Learning Purpose

This project was created to practice Python fundamentals and build confidence through hands-on coding.
